How the grade tools work

Every tool uses the standard US 4.0 grade scale: A = 4.0, B = 3.0, C = 2.0, D = 1.0, F = 0.0, with plus and minus steps in between. Weighted GPA adds +0.5 for Honors and +1.0 for AP / IB classes. Schools differ — some cap weighted GPA at 5.0, some use a different scale — so treat results as a planning estimate and check your school's own scale for official numbers.
